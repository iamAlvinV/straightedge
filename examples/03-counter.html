4.5:1

The contrast ratio body text must reach before anything else about a design is worth discussing.

It is a floor, not a target. A pairing that lands on 4.51 passes and still reads as thin. Straightedge computes the ratio with a script and refuses to round up.

WCAG 2.2, SC 1.4.3, Level AA

Contrast

What a pairing has to reach

  • 3:1

    Large text, and every non-text element that carries meaning

    Large means 24px, or 18.66px at bold weight. The same floor covers icons, form borders, and focus rings.

    SC 1.4.3 and SC 1.4.11, AA
  • 7:1

    Body text under the enhanced standard

    The bar Straightedge applies to government, healthcare, finance, and any work whose accessibility is publicly exposed.

    SC 1.4.6, Level AAA
  • 4.5:1

    Large text under the enhanced standard

    Paired with the 7:1 body figure. Logos, decorative text, and disabled controls sit outside both.

    SC 1.4.6, Level AAA

Size and target

What a hand has to hit

  • 24px

    Minimum interactive target, square

    Smaller targets can still pass through the spacing exception, which needs at least 24px between the centers of neighboring controls.

    SC 2.5.8, Level AA
  • 44px

    Enhanced target, and the working figure for touch

    Apple states 44pt, Material states 48dp. Straightedge treats 44 to 48 as the range for anything primary.

    SC 2.5.5, Level AAA
  • 80

    Characters per line, hard ceiling

    The working measure sits at 50 to 75, with 66 as the target for a single column. Set it in ch or em, never px.

    SC 1.4.8, Level AAA

Reflow and spacing

What the layout has to survive

  • 320px

    Width at which the page still works in one direction

    Equal to a 1280px desktop viewport at 400% zoom. Data tables, maps, and complex toolbars are the stated exceptions.

    SC 1.4.10, Level AA
  • 1.5

    Line height the user can force without breaking the page

    Applied at the same time as 0.12em letter spacing, 0.16em word spacing, and paragraph spacing at twice the font size.

    SC 1.4.12, Level AA
  • 16px

    Body floor on screen

    Straightedge holds this as a house rule rather than a criterion. Anything under 24px counts as normal text for contrast.

    House rule, tied to SC 1.4.3

Loading

What the browser has to finish

  • 2.5s

    Largest Contentful Paint

    Measured at the 75th percentile of real users, on mobile and desktop separately.

    Core Web Vitals
  • 200ms

    Interaction to Next Paint

    Javascript is the usual cause when this figure slips. Defer heavy scripts before touching anything else.

    Core Web Vitals
  • 0.1

    Cumulative Layout Shift

    Explicit width and height on every image, and font-display set to swap, remove most of what moves.

    Core Web Vitals

Where these came from

Every figure on this page is published by the W3C in Web Content Accessibility Guidelines 2.2, or by the Chrome team as a Core Web Vitals threshold. None of them were produced for this page.

The one exception is labeled: the 16px body floor is a Straightedge house rule, not a success criterion.
