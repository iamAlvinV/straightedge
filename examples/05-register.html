Shape catalog Twenty-two

The shape is picked before any visual rule, and the rotation script refuses one used in the last three runs. Six of these twenty-two are used in this example set, marked in the cells below.

Fourteen

Screen shapes. The rhythm of the sections, the entry point, the divider language.

  • Stack

    Hero, then evenly weighted sections down a single column. The honest default.

    Fits
    Docs, changelog, simple service page

  • Ledger

    Two columns. Left holds labels and metadata, right holds content. Reads like a spec sheet.

    Fits
    Technical products, pricing, comparison

  • Set 01

    Statement

    One oversized display line occupies the first screen alone. Everything else is small and below it.

    Fits
    Manifesto, launch, brand position

  • Bento

    Irregular tile grid, tiles of unequal span, one tile carries the hero.

    Fits
    Feature sets, dashboards, product tours

  • Broadsheet

    Long-form reading column, generous margins, sidenotes, a running head. No cards anywhere.

    Fits
    Essays, research, editorial, case studies

  • Set 02

    Console

    Interface first. The product is the hero, copy sits around it.

    Fits
    Tools, editors, dashboards

  • Index

    The page is a list. Rows, not cards. Rules between, not borders around.

    Fits
    Catalogs, archives, portfolios, directories

  • Split

    Fixed panel on one side, scrolling content on the other. Two speeds at once.

    Fits
    Case studies, product detail, galleries

  • Set 03

    Counter

    Numbers lead. Large figures set the hierarchy, prose supports them. Requires real numbers.

    Fits
    Reports, results, proof pages

  • Letter

    Addressed prose, signed. One voice speaking directly. Minimal structure.

    Fits
    Founder notes, apologies, announcements

  • Set 04

    Timeline

    Ordered progression down or across. The order is the content.

    Fits
    History, process, roadmap, changelog

  • Set 06

    Gallery

    Image-led, text is caption. Grid or sequence, never both.

    Fits
    Photography, product, portfolio

  • Readout

    Monospace, ruled, dense. Information allowed to look like information.

    Fits
    Developer tools, status pages, data

  • Placard

    One idea, one image, one line. Almost no scroll. The page is a single frame.

    Fits
    Events, campaigns, single-action pages

Eight

Print and static shapes. The composition of the field, and where the type sits in it.

  • Type slab

    Display type is the image. No photograph. Fills the field.

    Fits
    Gigs, statements, typographic posters

  • Frame

    Image occupies a bounded rectangle, type sits in the margin around it.

    Fits
    Exhibitions, film, product

  • Bleed

    Image runs edge to edge, type sits on top in one cluster.

    Fits
    Fashion, travel, atmosphere

  • Set 05

    Register

    Strict grid, content in cells, rules visible. Swiss discipline.

    Fits
    Schedules, programs, data posters

  • Stack cut

    Horizontal bands of different heights, one band per idea.

    Fits
    Line-ups, menus, multi-item announcements

  • Diagonal

    The primary axis is not horizontal. Everything aligns to a single tilt.

    Fits
    Sport, motion, energy

  • Center

    Symmetrical, axial, formal. Deliberate, not lazy.

    Fits
    Formal invitations, luxury, ceremony

  • Margin note

    Content sits low or off-center, most of the field is empty.

    Fits
    Luxury, minimal, high-restraint work
